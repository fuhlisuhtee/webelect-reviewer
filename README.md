# WebElect

A browser-based reviewer for Web Development and Machine Learning.

The Web Development bank includes 88 multiple-choice questions across HTML5, CSS3 and Responsive Design, JavaScript and the DOM, and PHP. The Machine Learning bank includes 67 questions across ML Workflow and Data, Training and Evaluation, Image Classification, and Audio Classification. Choose a topic or practice all topics; questions and answer choices are shuffled for each round. You can skip a question and return to it before finishing, review the correct answers and missed topics at the end, or retry only missed questions.

Open `index.html` in a browser to use the reviewer. No build step is required.
